# APAS Connect - Реализация иконок

## Обзор
APAS Connect теперь имеет профессиональную систему иконок с разделением между иконкой exe файла и адаптивными иконками системного трея.

## Реализованная функциональность

### 1. Иконка exe файла
- **Файл**: `icon.ico` (создан из `Icon.png`)
- **Назначение**: Отображается в проводнике Windows, на рабочем столе, в панели задач
- **Размеры**: Множественные разрешения (16x16, 32x32, 48x48, 256x256)

### 2. Адаптивные иконки системного трея
- **Генерация**: Программная генерация в реальном времени
- **Адаптация**: Автоматическое определение темы Windows (светлая/темная)
- **Цвета**:
  - Светлая тема: Темно-синий (#1a365d)
  - Темная тема: Светло-голубой (#60a5fa)
- **Размер**: 64x64 пикселей с прозрачностью

### 3. Определение темы системы
- **Метод**: Чтение реестра Windows (`HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize`)
- **Ключ**: `AppsUseLightTheme` (0 = темная тема, 1 = светлая тема)
- **Обновление**: Определяется при каждом создании иконки

### Сборка exe файла:
- **Инструмент**: PyInstaller
- **Команда**: `python build_exe.py`
- **Иконка**: `--icon=icon.ico`

## Файлы проекта
- `Icon.png` - Исходное изображение для exe иконки
- `icon.ico` - ICO файл для exe файла
- `icon_tray_black.png`, `icon_tray_white.png` - Исходные изображения для трея (больше не используются)
- `main.py` - Основной код с функциями иконок
- `build_exe.py` - Скрипт сборки PyInstaller

## Запуск
1. Запустите `python build_exe.py` для сборки
2. Запустите `dist/APAS_Connect.exe`
3. Иконка появится в системном трее с цветом, соответствующим теме Windows
